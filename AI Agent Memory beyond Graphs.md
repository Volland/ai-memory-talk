## Hypergraphs 

Mathematical generalization that allows a hyperedge to connect a set of nodes 

- capture a multimodal information as edges 
- capture a multilingual data as edges 
- allow complex multi entity facts as edges 
Key challenge - we could not reference edges as nodes 
---

## Metagraphs 
The most powerfull generalization of graphs 
- hyper edges 
- meta nodes 
- edge and node are homoiconic 
- edges and nodes could have a subgraph 

- [Declarative Semantic Memory Modeling for AI Agents with Metagraphs](https://ai.plainenglish.io/declarative-semantic-memory-modeling-for-ai-agents-with-metagraphs-51975a56d168)
